Core Differentiator03
RECOMMENDATION ENGINE

AI는 “얼마나 맞는지”, 서버는 “실제로 가능한지”를 판단합니다.

대화 분석

OpenAI API가 ChatGPT Export에서 관심사, 기술, 팀 선호, 가능 기간을 구조화해 추출합니다.

거리·조건 필터

서버가 Haversine 거리, 지역, 온라인 여부, 마감일, 참가 자격을 정확히 계산합니다.

순위화

AI 적합도 60% + 거리/온라인 20% + 마감 10% + 저장 이력 10%로 Top N을 선정합니다.
